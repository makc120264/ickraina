## Встановлення в існуючий проект Laravel
1. Скопіюйте файли/папки з цього репозиторію у відповідні місця вашого проекту.
2. Зареєструйте middleware-аліаси у app/Http/Kernel.php (див. [Завдання 1](Task-1.md)).
3. Застосуйте міграції: php artisan migrate.
4. Встановіть змінну оточення API_KEY в .env.
5. Викликайте API маршрутами, зазначеними вище, обов'язково передаючи заголовок X-API-KEY.

## Розгортання як самостійна програма (якщо Laravel вже доданий до репозиторію)
До цього репозиторію додано мінімальний каркас Laravel 11 (bootstrap/app.php, public/index.php, artisan, composer.json),
так що ви можете запустити проект як звичайний Laravel-додаток.

Кроки запуску:
1. Встановіть залежність:
   - `composer install`
2. Створіть .env (або скопіюйте з прикладу):
   - `cp .env.example .env`
   - Cгенеруйте APP_KEY: `php artisan key:generate`
   - Вкажіть налаштування БД та API_KEY в .env
3. Виконайте міграції:
   - `php artisan migrate`
4. Запустіть вбудований сервер:
   - `php artisan serve`
5. Звертайтеся до маршрутів API з розділу "Маршрути" (не забудьте заголовок X-API-KEY).

Примітки:
- Аліаси middleware `api.auth` та `validate.json` вже зареєстровані в bootstrap/app.php (Laravel 11-конфігурація),
  додаткова реєстрація в app/Http/Kernel.php не потрібна для цього репозиторію.
- Маршрути API автоматично підключаються через routes/api.php. Головна сторінка `/` повертає простий JSON зі статусом.
